# 原型草图工具设计计划

## 1. 项目概述

设计一款本地化的原型草图工具，用于快速构建UI原型。该工具将支持多画布管理、组件拖拽、实时预览等核心功能，帮助设计师快速构思和验证设计方案。

## 2. 核心功能需求

### 2.1 画布管理
- 支持创建多个画布
- 提供常用设备分辨率尺寸模板（手机、电脑等）
- 画布分辨率可自定义
- 当前编辑画布有明显标记

### 2.2 组件库
- 左侧面板展示各类基础组件
- 支持组件拖拽到画布
- 组件仅显示黑色线框，避免视觉干扰
- 包含以下组件：
  - 基础形状：方形、圆形、长方形、三角形
  - 内容组件：文字块、图片块、文字输入块、筛选块

### 2.3 组件操作
- 拖拽：支持组件在画布内自由移动
- 缩放：支持组件大小调整
- 选择：支持单个或多个组件选择

### 2.4 实时预览
- 右侧固定悬浮手机预览窗口
- 实时展示当前编辑画布的效果
- 预览窗口可调整尺寸和方向

## 3. 技术架构

### 3.1 前端技术栈
- **框架**：React + TypeScript
- **状态管理**：React Context + useReducer
- **样式**：Tailwind CSS
- **拖拽功能**：react-dnd
- **画布操作**：fabric.js 或自定义Canvas操作
- **构建工具**：Vite

### 3.2 项目结构
```
/src
  /components
    /Canvas
      Canvas.tsx           # 主画布组件
      CanvasItem.tsx       # 画布项组件
      CanvasList.tsx       # 画布列表组件
    /ComponentsLibrary
      ComponentItem.tsx    # 组件项
      ComponentsPanel.tsx  # 组件库面板
    /Preview
      PhonePreview.tsx     # 手机预览组件
    /common
      DraggableComponent.tsx  # 可拖拽组件
  /hooks
    useCanvas.ts           # 画布相关逻辑
    useComponents.ts       # 组件管理逻辑
  /context
    AppContext.tsx         # 应用状态管理
  /utils
    devicePresets.ts       # 设备分辨率预设
    canvasUtils.ts         # 画布工具函数
  /types
    index.ts               # 类型定义
  App.tsx                  # 主应用组件
  main.tsx                 # 入口文件
```

## 4. 实现步骤

### 4.1 项目初始化
1. 创建Vite React + TypeScript项目
2. 安装必要依赖（react-dnd, fabric.js, tailwindcss等）
3. 配置Tailwind CSS

### 4.2 核心组件开发
1. **画布管理系统**
   - 实现多画布创建和切换
   - 添加设备分辨率预设选择
   - 实现画布状态管理

2. **组件库**
   - 实现左侧组件面板
   - 添加基础组件类型
   - 实现组件拖拽功能

3. **画布编辑功能**
   - 实现组件拖拽到画布
   - 实现组件缩放和移动
   - 实现组件选择功能

4. **实时预览**
   - 实现右侧手机预览窗口
   - 实现实时更新预览
   - 支持预览窗口调整

### 4.3 样式和交互优化
1. 实现响应式布局
2. 添加操作反馈动画
3. 优化拖拽和缩放体验
4. 实现深色/浅色模式

## 5. 关键技术点

### 5.1 拖拽实现
使用react-dnd库实现组件从库到画布的拖拽，以及画布内组件的移动。

### 5.2 画布操作
使用fabric.js库实现画布的缩放、旋转和组件管理，提供流畅的编辑体验。

### 5.3 状态管理
使用React Context和useReducer管理应用状态，包括画布列表、当前画布、组件列表等。

### 5.4 实时预览
通过状态同步实现预览窗口的实时更新，确保设计效果的即时反馈。

## 7. 风险评估

### 7.1 潜在风险
- 画布操作性能问题（当组件数量较多时）
- 拖拽体验不流畅
- 实时预览同步延迟
- 跨设备兼容性问题

### 7.2 缓解措施
- 使用虚拟渲染优化大量组件场景
- 实现拖拽节流和防抖
- 使用Web Workers处理复杂计算
- 针对不同设备进行测试和优化
